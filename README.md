# Object-Oriented Design Practice

A collection of **Object-Oriented Design (OOD)** practice projects implemented in Python. This repository demonstrates core OOD principles including SOLID principles, design patterns, and clean architecture.

## 📚 Overview

This repository contains various OOD practice implementations to strengthen understanding of:
- Object-Oriented Programming fundamentals
- SOLID principles
- Design patterns
- Clean architecture
- Test-driven development with pytest

## 🎯 OOD Principles Practiced

### Core OOP Concepts
- **Abstraction** - Abstract base classes and interfaces
- **Encapsulation** - Data hiding and information protection
- **Inheritance** - Code reuse through class hierarchies
- **Polymorphism** - Flexible interfaces and method overriding

### SOLID Principles
- **S** - Single Responsibility Principle
- **O** - Open/Closed Principle
- **L** - Liskov Substitution Principle
- **I** - Interface Segregation Principle
- **D** - Dependency Inversion Principle

### Design Patterns
- Dependency Injection
- Service-Oriented Architecture
- Facade Pattern
- And more...

## 🚀 Getting Started

### Prerequisites
- Python 3.10+
- pytest

### Installation

```bash
# Clone the repository
git clone <repository-url>
cd OOD

# Install dependencies
pip install -r requirements.txt
```

### Running Tests

```bash
# Run all tests
pytest

# Run with verbose output
pytest -v

# Run specific test file
pytest tests/test_library_management_system.py
```

## 🧪 Testing

This repository uses **pytest** for unit testing. Test files are located in the `tests/` directory.

```bash
# Run tests with coverage
pytest --cov

# Run tests with detailed output
pytest -v -s
```
